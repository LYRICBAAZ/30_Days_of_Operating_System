## 📂 About This Repo

This repo breaks a full Operating Systems course into **30 bite-sized days**. Each day lives in its own folder with a single PDF covering that day's topic — read one, take notes, check it off, move to the next.

It's organized into 3 units with short revision days built in:

- **Unit 1 — OS Basics** (Day 1–9)
- **Unit 2 — Process Management & Synchronization** (Day 10–22)
- **Unit 3 — Memory Management** (Day 23–30)

## 🧭 How to Use This Repo

1. Open the day's folder and read the PDF.
2. Summarize what you learned in your own words (a notes app, an Obsidian vault, whatever works).
3. Check off the day in the table above.
4. Optional: post a short recap of the day's topic — writing it out is one of the best ways to make it stick.

## 🧠 Topics Covered

- OS fundamentals, types of OS, kernels & system calls
- Boot process, 32-bit vs 64-bit, storage hierarchy
- Processes, process states, context switching
- CPU scheduling algorithms (FCFS, SJF, Priority, RR, MLQ, MLFQ)
- Concurrency, critical sections, semaphores, dining philosophers
- Deadlocks — prevention, avoidance, detection, recovery
- Memory management — contiguous allocation, paging, segmentation
- Virtual memory, demand paging, page replacement, thrashing
